1. Introduction & App Identity

This Privacy Policy explains how Retro Rage Arcade ("the Game", "the Application", "we", "us", or "our"), with Android package name com.antigravity.retroragearcade, handles data when installed on Android devices.

The game is developed by Idea AI using the open-source Godot Engine (version 4.7.2). Retro Rage Arcade is designed and built as a standalone, offline 2D arcade platformer.

✓ Core Privacy Standard: The Application does not collect, record, track, transmit, monetize, sell, or distribute personal data from its players.

2. Information We Do Not Collect

Inspection of the application code, build configurations, and compiled release artifacts confirms that Retro Rage Arcade contains no personal data collection mechanisms:

  • No Personal Information: We do not ask for, collect, or store names, email addresses, physical addresses, phone numbers, age, gender, or personal identifiers.
  • No Account or Login Credentials: The game does not offer or require user accounts, passwords, social media logins (e.g., Google Sign-In, Facebook Login), or cloud player profiles.
  • No Unique Device Identifiers: The game does not collect or access Android IDs, Advertising IDs (GAID), MAC addresses, IMEI numbers, or hardware serial numbers.
  • No Location Data: The game does not access precise (GPS) or approximate (network-based) location.
  • No Financial or Payment Data: There are no in-app purchases (IAP), subscriptions, paid unlocks, or payment processors. The game is completely free to play.
  • No Telemetry or Behavioral Tracking: We do not track player session times, in-game death events, gameplay analytics, or behavioral telemetry.

3. Locally Stored Game Progress

To preserve gameplay achievements between sessions, the game stores a minimal JSON save file strictly on your local device:

  • Storage File Path: The game writes to Godot's user://retro_rage_save.json path. On Android, this resolves to the application's private internal storage sandbox: /data/data/com.antigravity.retroragearcade/files/retro_rage_save.json.
  • Data Elements Stored:
    1. schema_version: An integer (currently 1) used to maintain save file format compatibility.
    2. highest_unlocked_level: An integer (range 1 to 20) indicating level progression.
    3. completed_levels: An array of integers identifying the specific stages completed by the player.
    4. sfx_enabled: A boolean flag (true / false) for the player's sound effects audio setting.
    5. music_enabled: A boolean flag (true / false) for the player's music audio setting.

Local Isolation: This save file exists exclusively on the local device hardware. It is never transmitted across any network and is not synchronized to any external server.

6. Data Retention & User Deletion Rights

Because we store no user data on external servers, we retain no remote personal data to delete.

How to Delete Your Local Game Progress:

  1. Clear App Data: In Android settings, go to Settings > Apps > Retro Rage Arcade > Storage > Clear Storage / Clear Data. This permanently removes the local save file (retro_rage_save.json) from internal storage and resets progress to level 1.
  2. Uninstall the Game: Uninstalling Retro Rage Arcade removes the application package and deletes its internal storage files.
